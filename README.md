# Horticultural Production and Research

Bookdown GitBook lecture website. The only deployed output format is `bookdown::gitbook`.

## Build locally

1. Open `Horticultural-Production-and-Research.Rproj` in RStudio with R 4.5.0.
2. Restore `renv/activate.R` from your original tracked project if you have it. This ZIP did not contain it. Alternatively, after installing `renv`, run `renv::activate()` once to generate the project bootstrap, and commit its `renv/` activation/configuration files.
3. Run `renv::restore()` to install the dependencies from `renv.lock`.
4. Run `bookdown::render_book("index.Rmd", output_format = "bookdown::gitbook")`.
5. Open `_book/index.html`.

Do not run `renv::snapshot()` as part of rendering: package lockfile updates should be deliberate and reviewed.

## Publish

`.github/workflows/bookdown-pages.yml` renders GitBook on pushes to `main` or `master` and on manual runs. In repository **Settings → Pages**, select **GitHub Actions** as the build/deployment source. Disable the older `peaceiris/actions-gh-pages` workflow to avoid two competing deployments. The workflow publishes `_book/` without committing generated HTML.

## Notes

- `_bookdown.yml` explicitly lists included chapters and their order. Some chapters are intentionally excluded by comments.
- `packages.bib` is generated by an existing knitr chunk; this can modify a tracked source file during builds. Consider changing this later if the bibliography does not need dynamically discovered package citations.
- The archive supplied for this cleanup did not contain `renv/activate.R`; restore or generate it before expecting an entirely clean clone to bootstrap identically on local machines.
- The old standalone `Book.Rmd` and `Book.html` were generated artifacts and are intentionally excluded from the cleaned source tree.
